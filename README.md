# AX Module Studio Frontend

React frontend repository for AX Module Studio.

## Current state

This is the governance-only owner bootstrap. Product source, package locks, Docker assets, and application scaffolding have not been created yet.

Implementation starts only after the approved environment gate and Stage 0 contract work.

## Workflow

Normal changes use `latest dev -> feature/<work-slug> -> pull request to dev`. Direct pushes to `dev` and `main` are reserved for explicitly approved owner bootstrap or emergency recovery.
